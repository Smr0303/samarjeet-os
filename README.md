# samarjeet-os

The Windows-95 style OS that runs inside the monitor at
[samarjeet-portfolio-3d.vercel.app](https://samarjeet-portfolio-3d.vercel.app), also served on its own at
[samarjeet-os.vercel.app](https://samarjeet-os.vercel.app).

Forked from [henryjeff/portfolio-inner-site](https://github.com/henryjeff/portfolio-inner-site) (MIT).
The OS shell, window manager and games are Henry Heffernan's; the showcase content is mine.

```bash
npm i
npm start        # CRA dev server on :3000
npm run build    # static build into build/
```

Content lives in `src/components/showcase/`. The Music and Art project pages are present but
unrouted until there is something to put in them.
